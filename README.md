# ASSIGNMENT-2-SEPTEMBER
Excel Power Query – Data Cleaning

📌 Project Overview

This project demonstrates data cleaning and transformation using Microsoft Excel Power Query.

🛠️ Tools Used

* Microsoft Excel
* Power Query
* GitHub

🧹 Tasks Completed

* Handled missing values
* Corrected inconsistent data
* Removed duplicate records
* Standardized product and category names
* Split Product ID into Day, Month & Country Code
* Created Manufacturing Date
* Merged Product Name and Brand Name
* Applied currency and conditional formatting
* Prepared the dataset for analysis

📊 Final Dataset

The cleaned dataset contains:

* Product Brand
* Price ($)
* Quantity
* Category
* Country Code
* Manufacturing Date

🎯 Outcome

A clean, structured, and analysis-ready dataset created using Excel Power Query.
